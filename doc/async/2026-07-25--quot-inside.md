### Why this is useful in Real-World CS / Math:

1. **Term Rewriting / Lambda Calculus**:
   A single-step $\beta$-reduction $M \to_\beta N$ is **not** symmetric or reflexive. But if you take `Quot (· →_β ·)`, you instantly get the type of **Lambda Terms modulo $\beta$-convertibility**!
2. **Free Groups**:
   You define single-step word reduction $w_1 \cdot x \cdot x^{-1} \cdot w_2 \sim w_1 \cdot w_2$ (not symmetric or transitive). `Quot` on this rule gives you the **Free Group**.
3. **Graph Algorithms**:
   Converting single-step directed transitions into connected components or state equivalences without manually defining paths or transitive closures first.

## The big idea: two layers

`Quot` is Lean's **primitive quotient type**. It's one of the very few things baked directly into the *kernel* rather than defined in the library. But not all six names you listed are primitives — only four are. There are two distinct layers:

| Name         | What it really is                                 | Trusted by kernel?   |
| ------------ | ------------------------------------------------- | -------------------- |
| `Quot`       | kernel primitive (`QuotKind::Type`)               | yes                  |
| `Quot.mk`    | kernel primitive (`QuotKind::Ctor`)               | yes                  |
| `Quot.lift`  | kernel primitive (`QuotKind::Lift`)               | yes                  |
| `Quot.ind`   | kernel primitive (`QuotKind::Ind`)                | yes                  |
| `Quot.sound` | an **axiom** written in Lean                      | yes (as an axiom)    |
| `Quot.rec`   | an ordinary **definition** derived from the above | no — it's just a def |

So when you `#check` these, four of them are things the kernel *manufactures*, one is an axiom in the library, and one is regular Lean code.

### The computation rule (the special part)

The kernel *hard-codes* the reduction rules for `Quot.lift` and `Quot.ind`. This is the defining behavior that can't be expressed as ordinary Lean:

```
Quot.lift f h (Quot.mk r a)  ↝  f a
Quot.ind   mk (Quot.mk r a)  ↝  mk a
```

This lives in `quot_reduce_rec`:
- C++: `origin-master-src/kernel/quot.h:39`
- Rust: `src/rust/runtime/src/kernel_type_checker.rs:3085` (`quot_reduce_rec`), invoked from `reduce_recursor` (line 3072), gated on `lean_environment_is_quot_initialized`.

```
unsafe fn quot_reduce_rec(
    &mut self,
    e: *mut LeanObject,
) -> Result<Option<*mut LeanObject>, KernelError> {
    // Head constant of the application spine.
    let mut head = e;
    while lean_expr_is_app(head) {
        head = lean_expr_get_app_fn(head);
    }
    if !lean_expr_is_const(head) {
        return Ok(None);
    }
    let head_name = lean_expr_get_const_name(head); // borrowed
    let mk_pos: usize;
    let arg_pos: usize;
    if lean_name_eq(head_name, load_global(&G_QUOT_LIFT_NAME)) {
        mk_pos = QUOT_LIFT_MK_POS;
        arg_pos = QUOT_LIFT_ARG_POS;
    } else if lean_name_eq(head_name, load_global(&G_QUOT_IND_NAME)) {
        mk_pos = QUOT_IND_MK_POS;
        arg_pos = QUOT_IND_ARG_POS;
    } else {
        return Ok(None);
    }

    // Collect args in application order (all borrowed, pointing inside `e`).
    let mut args: Vec<*mut LeanObject> = Vec::new();
    let mut cur = e;
    while lean_expr_is_app(cur) {
        args.push(lean_expr_get_app_arg(cur));
        cur = lean_expr_get_app_fn(cur);
    }
    args.reverse();
    if args.len() <= mk_pos {
        return Ok(None);
    }

    // whnf the major premise (the value that should be a `Quot.mk`).
    let mk_arg = args[mk_pos];
    lean_inc(mk_arg);
    let mk = self.whnf(mk_arg)?; // owned

    // Require `mk` to be exactly `Quot.mk α r a` (a constant head + 3 args).
    let mut mk_head = mk;
    let mut mk_nargs = 0usize;
    while lean_expr_is_app(mk_head) {
        mk_nargs += 1;
        mk_head = lean_expr_get_app_fn(mk_head);
    }
    if !lean_expr_is_const(mk_head)
        || !lean_name_eq(
            lean_expr_get_const_name(mk_head),
            load_global(&G_QUOT_MK_NAME),
        )
        || mk_nargs != QUOT_MK_NUM_ARGS
    {
        lean_dec(mk);
        return Ok(None);
    }

    // r := f a, where f = args[arg_pos] and a = last arg of `Quot.mk` (the element).
    let f = args[arg_pos];
    let elem = lean_expr_get_app_arg(mk); // borrowed (inside mk)
    lean_inc(f);
    lean_inc(elem);
    let mut r = lean_expr_mk_app(f, elem); // consumes f + elem
    lean_dec(mk);

    // Re-apply any over-saturated args beyond the eliminator's expected arity.
    let elim_arity = mk_pos + 1;
    for &a in &args[elim_arity..] {
        lean_inc(a);
        r = lean_expr_mk_app(r, a);
    }
    Ok(Some(r))
}
```

The argument-position constants encode the layout (`kernel_type_checker.rs:1214`):
- `Quot.lift {α} r {β} f h q` → the `Quot.mk` is arg index 5, `f` is arg 3
- `Quot.ind {α} {r} {β} mk q` → the `Quot.mk` is arg index 4, `mk` is arg 3
- `Quot.mk {α} r a` → fully applied at 3 args

`quot_reduce_rec` whnf's the major premise, checks it's literally `Quot.mk α r a`, then rebuilds `f a` (resp. `mk a`) and re-applies any over-saturated trailing args.

## Layer 2 — `Quot.sound` and `Quot.rec` (library, not kernel primitives)

These are **not** produced by `init_quot`. They live in `src/Init/Core.lean` inside `namespace Quot`.

### `Quot.sound` — an axiom (`Core.lean:1789`)

```lean

```

This is the propositional content of quotients ("related elements are equal"). The kernel gives it no computation rule — it's a genuine axiom. This is the one that shows up in `#print axioms` for anything built on quotients.

### `Quot.rec` — a *derived definition* (`Core.lean:1870`)

`Quot.rec` is **not** primitive. It's assembled from the primitives plus `Quot.sound` and `Eq` machinery. The build-up in `Core.lean:1836-1874`:

- `Quot.indep` (1838) — packs `f a` into a `PSigma`
- `Quot.indepCoherent` (1841) — proves `indep` respects `r`, using `sound`
- `Quot.liftIndepPr1` (1847) — proves the first projection of the lifted `indep` recovers `q`, via `Quot.ind`
- `Quot.rec` (1870) itself:
  ```lean
  @[elab_as_elim] protected abbrev rec
      (f : (a : α) → motive (Quot.mk r a))
      (h : (a b : α) → (p : r a b) → Eq.ndrec (f a) (sound p) = f b)
      (q : Quot r) : motive q :=
    Eq.ndrecOn (Quot.liftIndepPr1 f h q) ((lift (Quot.indep f) (Quot.indepCoherent f h) q).2)
  ```

So `Quot.rec` reduces via the ordinary reduction of the underlying `Quot.lift` — no special kernel support. Also in that region: `Quot.liftOn`, `Quot.inductionOn`, `Quot.recOn` (1891), plus the beta rules `liftBeta`/`indBeta` (proved by `rfl`, i.e. they hold *definitionally* thanks to the kernel computation rule).
