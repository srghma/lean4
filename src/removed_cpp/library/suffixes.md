# `library/suffixes` (`library/suffixes.h`)

## Location of corresponding Rust implementation
No corresponding Rust file exists yet. The original C++ file (`library/suffixes.h`) simply contained constant string definitions for common Lean name suffixes (`rec`, `casesOn`, `noConfusion`, `noConfusionType`).
In Rust, some constants are stored in `src/rust/lean_runtime/src/library_constants.rs`, but the specific suffixes strings don't seem to have a dedicated Rust equivalent module.
