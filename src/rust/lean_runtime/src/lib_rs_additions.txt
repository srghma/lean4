The Rust files re-export the functions they own under their original
LEAN_EXPORT names; as long as we do NOT also compile the C++ versions
of those same symbols, there is no conflict.

To avoid double-definition, wrap the C++ definitions that are now in
Rust with a preprocessor guard, OR — easier for now — rely on link
ordering (Rust staticlib listed before C++ objects so Rust wins).

     #ifndef LEAN_RUST_RUNTIME
   and add -DLEAN_RUST_RUNTIME to COMPILE_DEFINITIONS when building
   with the Rust runtime.
