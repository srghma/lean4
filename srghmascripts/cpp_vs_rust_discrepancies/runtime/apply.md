# `runtime/apply` (`runtime/apply.h` and `runtime/apply.cpp`)

## Location of corresponding Rust implementation
The implementation corresponds to the Rust file `src/rust/lean_runtime/src/runtime_apply.rs`.

## Discrepancies and issues
- **Algorithm & Approach**: The C++ code consisted of massive, auto-generated boilerplate defining `lean_apply_1` through `lean_apply_16`, unboxing arguments and invoking fixed-arity function pointers. The Rust implementation provides the exact same `lean_apply_X` functions in `runtime_apply.rs`, likely generated by a similar macro or script to keep parity.
- **Memory Model**: No fundamental differences. Rust applies the same logic: extracting the closures, checking arity vs. fixed arguments, checking for exclusive (unshared) ownership (`lean_is_exclusive`), and either executing directly, currying, or re-allocating an updated closure.
- **Porting Status**: Fully ported. Both provide the necessary C ABI `lean_apply_n` and individual `lean_apply_X` entry points for Lean's functional application runtime.
